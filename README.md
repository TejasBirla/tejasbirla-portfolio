# Tejas Birla — Portfolio

A minimal, Spotify-inspired personal portfolio built with React and Vite. It showcases my projects, experience, tech stack, live GitHub contributions and a bit of my music taste, all in a clean, responsive, dark-themed layout.

🔗 **Live:** [tejasbirla-portfolio.vercel.app](https://tejasbirla-portfolio.vercel.app)

## Features

- 🎧 Spotify-style dashboard layout with a grid of cards
- 💼 Featured and side projects with live links
- 🧑‍💻 Professional experience timeline
- 📊 Real-time GitHub contribution graph
- 🛠️ Programming languages and tools I work with
- 🎵 Embedded Spotify playlist
- 📱 Fully responsive across desktop, tablet and mobile

## Tech Stack

- **React** (JavaScript / JSX)
- **Vite** — build tooling and dev server
- **Tailwind CSS** — styling
- **Framer Motion** — animations
- **React Icons** — iconography

## Project Structure

```
portfolio/
├── frontend-new/   # Current portfolio (live) — React + Vite
└── frontend-old/   # Previous portfolio (archived)
```

## Getting Started

```bash
cd frontend-new

# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build
```

The dev server runs at `http://localhost:5173`.
